# Hantavirus Tracker 🗺️

**[Français](#français) · [English](#english)**

---

## Français

Tableau de bord cartographique qui suit l'éclosion de hantavirus Andes (ANDV) liée au navire **MV Hondius** : cas confirmés et sous surveillance par pays, trajet estimé du navire d'Ushuaia à Rotterdam et fil d'actualités avec les sources (OMS, CDC, ECDC, ProMED-mail).

### Points forts
- Carte **Leaflet** avec les cas, filtrables par statut (confirmé / sous surveillance) et recherche par pays ou région
- Barre de statistiques, liste des cas et fil d'actualités dans les panneaux latéraux
- Interface en espagnol, anglais et français grâce à un petit composable `useI18n`
- Les données vivent dans un seul fichier statique, `public/data/cases.json`, généré par `scripts/fetch_cases.py`
- Une **GitHub Action** régénère le fichier aux deux jours et le commite seulement s'il a changé
- Déployé sur Netlify

### Technologies
Vue 3 · Vite · Leaflet · Python · GitHub Actions · Netlify

### Exécution locale
```bash
npm install
npm run dev
```

Pour régénérer les données :
```bash
pip install -r scripts/requirements.txt
python scripts/fetch_cases.py
```

Pour ajouter ou corriger un cas, modifiez `CASOS` ou `NEWS_FEED` dans `scripts/fetch_cases.py` et relancez le script.

## English

Map dashboard tracking the Andes hantavirus (ANDV) outbreak linked to the **MV Hondius** ship: confirmed and monitored cases by country, the ship's estimated route from Ushuaia to Rotterdam, and a news feed with sources (WHO, CDC, ECDC, ProMED-mail).

### Highlights
- **Leaflet** map of cases, filterable by status (confirmed / monitoring) and searchable by country or region
- Stat bar, case list and news feed in the side panels
- UI in Spanish, English and French through a small `useI18n` composable
- Data lives in a single static file, `public/data/cases.json`, generated by `scripts/fetch_cases.py`
- A **GitHub Action** regenerates the file every two days and commits it only when it changed
- Deployed on Netlify

### Stack
Vue 3 · Vite · Leaflet · Python · GitHub Actions · Netlify

### Run locally
```bash
npm install
npm run dev
```

To regenerate the data:
```bash
pip install -r scripts/requirements.txt
python scripts/fetch_cases.py
```

To add or correct a case, edit `CASOS` or `NEWS_FEED` in `scripts/fetch_cases.py` and run the script again.
